# Screenshots

截图用于 README 展示，请放入本目录并按下面的文件名命名。文件名与文中引用保持一致，避免图片失效。

## 需要的截图

| 文件名 | 内容 | 建议尺寸 |
|--------|------|----------|
| `01-tooltip.png` | 网页中划词后弹出的翻译卡片（带「词库」或「AI」标签） | 约 900×500 |
| `02-popup.png` | 点击工具栏图标后的弹窗，展示一次翻译结果 | 360×480（原始弹窗尺寸即可） |
| `03-options.png` | 设置页「大模型 API」区域，含服务商预设按钮与语言选择 | 约 1000×700 |
| `04-page-translate.png` | 整页翻译后的页面，含底部进度/状态条与「撤销」按钮 | 约 1200×700 |

可选：

| 文件名 | 内容 |
|--------|------|
| `05-before-after.png` | 同一页面翻译前后的对比 |

## 拍摄要求

- 使用 Windows 缩放 100% 下的系统截图（`Win + Shift + S`），避免模糊
- 只截取插件相关区域，去掉与功能无关的浏览器书签栏
- **务必遮挡个人信息**：不要出现 API Key、账号头像、私密网页内容
- 界面语言与截图用途保持一致：中文截图放入本目录，英文截图可命名为 `*-en.png`
- 单张图片建议 < 500 KB，可用 [Squoosh](https://squoosh.app/) 压缩后再放入

## 加入 README

截图补齐后，在 `README.md` 和 `README.en.md` 的 `## Screenshots / ## 截图` 章节里加入：

```markdown
| 划词翻译 | 弹窗翻译 |
|---|---|
| ![划词翻译](screenshots/01-tooltip.png) | ![弹窗翻译](screenshots/02-popup.png) |
```

图片未齐前，README 中使用文字链接指向本文件，避免出现破图。
